# ferdisahin/homebrew-tap

Personal Homebrew tap.

## Install

```bash
brew install ferdisahin/tap/hman
```

## Total Command (macOS)

Native dual-pane file manager for macOS 13 or later, available for Apple Silicon and Intel. Developer ID signed and notarized by Apple. Version 0.2.4 is an early preview.

```sh
brew install --cask ferdisahin/tap/total-command
```

To update: `brew update && brew upgrade --cask ferdisahin/tap/total-command`.
To uninstall: `brew uninstall --cask total-command`. Preferences are retained unless you use `--zap`.
